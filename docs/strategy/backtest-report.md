# Backtest Report: Trading Terminal Strategy Validation

> Last updated: 2026-07-25. Source: task-049..065 backtest runs, task-054..063 1min candle loading.
> This document describes the backtesting methodology, patterns, strategies, matrices, filters, benchmarks, results, and conclusions.

## 1. Overview

The backtest engine validates rule-based trading strategies on historical MOEX stock data. It is deterministic (same inputs → same outputs), long-only, and accounts for transaction costs.

**Key parameters:**
- Entry: open of the bar AFTER the signal bar (T+1). No look-ahead bias.
- Side: LONG only. BUY opens a position (if flat); SELL is an exit trigger.
- Costs: commission 0.03% per side (0.06% round-trip). Slippage modelled separately (default 0 ticks).
- Position size: fixed 1 lot (v1). No capital sizing.
- Universe: top-30 stocks by volume (fixed snapshot, selection_bias=true).
- Data: 1min candles from MOEX ISS API (2 years for SBER/GAZP/VTBR; ~1 month for other 27 tickers from T-Bank API 30min raw).

**Engine:** `backend/app/analytics/backtest_engine.py` + `backtest_models.py`.
**Orchestrator:** `backend/app/api/backtest_jobs.py` (POST /api/backtest/run, GET /api/backtest/run/status, shared jobs_state lock).

## 2. Patterns (10 total)

Signals are generated by 10 technical analysis patterns across 5 categories. Each pattern analyses indicators (RSI, SMA, Bollinger Bands, volume, candle shapes) and outputs BUY or SELL with a confidence score.

| Category | Pattern | Description | Signal logic |
|---|---|---|---|
| Trend | Trend_SMA_Alignment | SMA alignment (20/50/200) | BUY if SMA20 > SMA50 > SMA200 (bullish alignment); SELL if reverse |
| Mean Reversion | MR_RSI_Reversal | RSI reversal from extremes | BUY if RSI crosses up from <30 (oversold); SELL if crosses down from >70 (overbought) |
| Breakout | BO_BB_Squeeze | Bollinger Bands squeeze | BUY/SELL on breakout direction after volatility contraction (BB width < threshold) |
| Volume | VOL_Spike | Volume spike (>2x average) | BUY/SELL in direction of price move when volume > 2× 20-bar average |
| Volume | VOL_Low_Pullback | Low-volume pullback | BUY if price pulls back on low volume (weak sellers) in uptrend |
| Price Action | PA_Hammer | Hammer candle | BUY if hammer appears after downtrend (long lower shadow, small body at top) |
| Price Action | PA_HangingMan | Hanging man candle | SELL if hanging man appears after uptrend (same shape as hammer, but at top) |
| Price Action | PA_Engulfing | Engulfing pattern | BUY if bullish engulfing (green candle > prior red); SELL if bearish engulfing |
| Price Action | PA_ThreeWhiteSoldiers | Three white soldiers | BUY if 3 consecutive green candles, each closing higher (rare, ~20 signals on short history) |
| Price Action | PA_ThreeBlackCrows | Three black crows | SELL if 3 consecutive red candles, each closing lower (rare, ~41 signals on short history) |

**Signal aggregation:** On each bar, multiple patterns may fire simultaneously. The signal record stores `total_signals` (count of patterns that agreed) and `pattern_name` (comma-separated list). Example: `total_signals=3, pattern_name="MR_RSI_Reversal, VOL_Spike, PA_Engulfing"` means 3 patterns signalled BUY on the same bar.

## 3. Entry Rules

Entry occurs when a BUY signal fires, subject to optional filters:

- **No filter (baseline):** Enter on any BUY signal.
- **Filter by total_signals:** Enter only if `total_signals >= N` (N=2 or N=3). Stronger consensus → fewer but higher-quality signals.
- **Filter by confidence:** Enter only if `confidence >= C` (C=0.5, 0.7, 0.9). Higher confidence → fewer signals.
- **Combined filter:** `total_signals >= 2 AND confidence >= 0.9` (used in filter baselines).

Entry price = open of the next bar (T+1). If the signal fires on the last available bar (no T+1), the trade is skipped as "untradeable" (not an error).

## 4. Exit Rules

Four exit mechanisms, tested in combinations:

| Exit type | Description | Parameter |
|---|---|---|
| Stop-loss | Exit if price drops to entry − stop_atr × ATR(14) | stop_atr ∈ {1.0, 2.0} |
| Take-profit | Exit if price rises to entry + take_atr × ATR(14) | take_atr ∈ {1.0, 2.0} |
| Holding expiry | Exit after N bars regardless of price | holding_bars ∈ {3, 6, 12} |
| Signal exit (sigOn) | Exit on any opposite (SELL) signal | signal_exit=True, signal_exit_min_total=1 |
| Signal exit strong (sigOn_ts3) | Exit only on opposite signal with total_signals ≥ 3 | signal_exit=True, signal_exit_min_total=3 |
| No signal exit (sigOff) | Ignore opposite signals; exit only by stop/take/holding | signal_exit=False |

**Priority:** Stop and take are checked on bar high/low. If both hit on the same bar, stop wins (conservative). Gap-open beyond a level → fill at open. Holding expiry and signal exit use close price.

## 5. Backtest Matrix

The full matrix tests all combinations of exit parameters:

- **Holding:** {3, 6, 12} bars
- **Stop ATR:** {1.0, 2.0}
- **Take ATR:** {1.0, 2.0}
- **Signal exit:** {sigOn (any), sigOff (none)} — and in task-064, sigOn_ts3 (strong signal only)

Total: 3 × 2 × 2 × 2 = **24 combinations** (or 30 with filter baselines, see below).

Each combination is run on the full universe (30 tickers) or a subset (e.g., SBER/GAZP/VTBR for per-ticker analysis). Results are stored in `backtest_runs`, `backtest_trades`, `backtest_equity`, `backtest_metrics`.

## 6. Filter Baselines

In addition to the matrix, filter baselines test entry quality:

- **filter_ts2_c0.5:** total_signals ≥ 2 AND confidence ≥ 0.5
- **filter_ts2_c0.7:** total_signals ≥ 2 AND confidence ≥ 0.7
- **filter_ts2_c0.9:** total_signals ≥ 2 AND confidence ≥ 0.9
- **filter_ts3 (task-064/065):** total_signals ≥ 3 (with sigOn/sigOff/sigOn_ts3 exits)

Each filter baseline is run with sigOn and sigOff exits, using the best matrix rules (h6_s2_t1 or h12_s2_t1). Total: 3 filters × 2 exits = **6 combinations** (or 9 with ts3).

## 7. Benchmarks

Two benchmarks for comparison:

- **Buy&hold:** For each trade, compute (close_at_exit / close_at_entry − 1) × 100%. This is the return if you entered at the same time and held until the strategy's exit bar, without stops/takes. Averaged over all trades in the group.
- **Random:** Generate len(trades) random long entries on random bars of the same tickers, holding the same bars_held as the matched real trade. Averaged return. Tests whether the strategy beats random entry.

**Note:** Buy&hold is computed over the strategy's holding period, not the full 2-year window. It answers "did the strategy's entry timing + exit rules add value vs. just holding?"

- **All 30 combinations unprofitable** (PF < 1, expectancy < 0).
- Best: filter_ts2_c0.9_sigOn (PF 0.952, exp −0.033%, n=1869).

## 9. Results: Long History (2 years, SBER/GAZP/VTBR)

From task-062 (3 tickers, 2 years, 12 rule combos × sigOn/sigOff + 3 filters × sigOn/sigOff = 30 runs):
- **All 30 combinations unprofitable** (PF < 1, expectancy < 0).
- Best: filter_ts2_c0.9_sigOn (PF 0.800, exp −0.066%, n=310).
- Matrix best: h6_s2_t1_sigOn (PF 0.744, exp −0.093%, n=1984).
- sigOn better than sigOff for filters; for matrix, sigOff sometimes has higher PF but similar/worse expectancy.
- Strategy underperforms buy&hold and random on strong signals (filter_ts2_c0.9: buy&hold +0.023%, random +0.090%, strategy −0.066%).

From task-064 (ts≥3 experiment, 3 tickers, h6/h12 × sigOn_any/sigOn_ts3/sigOff = 6 runs):
- sigOn_any (exit on any signal) best: h6_s2_t1_sigOn_any PF 0.787, exp −0.086%.
- sigOn_ts3 (exit on strong signal only) worse: PF 0.725, exp −0.159%.
- sigOff (no signal exit) worse: PF 0.724, exp −0.166%.
- Conclusion: exit by any opposite signal is better than waiting for a strong signal or ignoring signals.

## 10. Per-Ticker Analysis (Long History, ts≥3)

From task-065 (3 tickers separately, ts≥3, h6/h12 × sigOn/sigOff = 12 runs):

| Ticker | Best PF | Strategy | Exp % | WR % | Buy&Hold % | Profitable? |
|---|---|---|---|---|---|---|
| GAZP | 0.870 | h6_s2_t1_sigOn | −0.058 | 45.8 | −0.104 | No |
| VTBR | 0.868 | h12_s2_t1_sigOff | −0.106 | 63.2 | +0.172 | No |
| SBER | 0.581 | h6_s2_t1_sigOn | −0.122 | 46.2 | +0.040 | No |

- **GAZP:** Best PF (0.870), but buy&hold is negative (−0.104%). GAZP fell during holding periods; strategy loses less than buy&hold. Not edge, just "losing less on a falling market."
- **VTBR:** Buy&hold strongly positive (+0.172%), but strategy loses (−0.08% to −0.12%). Exit rules (stops/takes) cut the profitable move. VTBR is the only ticker where sigOff is competitive with sigOn (PF 0.868 vs 0.833).
- **SBER:** Worst PF (0.581). sigOff catastrophic (PF 0.44, exp −0.30%). Buy&hold slightly positive (+0.04%) for sigOn, but strategy loses −0.12%.

## 11. Key Findings

1. **No profitable combination.** All 30+ matrix/filter combinations have PF < 1 and expectancy < 0 after 0.06% commission. Rule-based strategies do NOT have edge on MOEX top-3 (SBER/GAZP/VTBR) over 2 years.

2. **Signals carry weak directional info.** Buy&hold on strong signals (ts≥2, conf≥0.9) is positive (+0.023% to +0.172% depending on ticker), meaning signals slightly predict direction. But the edge is smaller than transaction costs.

3. **Exit rules hurt.** Strategy underperforms buy&hold by 0.09–0.29%. Stops/takes cut profitable moves; holding expiry forces exits at bad times. The best exit is "exit on any opposite signal" (sigOn), but even that is unprofitable.

4. **Filters improve quality but don't save.** total_signals≥2 + confidence≥0.9 raises PF from ~0.74 (matrix best) to ~0.80–0.95, and expectancy from −0.093% to −0.033–0.066%. Still negative.

5. **High win rate is a trap.** sigOff has WR 52–63% (vs sigOn 35–46%), but PF is lower. Wide stop (2 ATR) lets price move in favor (high WR), but losses are large when stop hits (low PF). Do not optimize for win rate; optimize for PF/expectancy.

6. **Commission kills short-horizon strategies.** Avg bars held 2–3. Gross expectancy ~+0.03–0.05% (from buy&hold), commission 0.06% round-trip → net negative. For profitability, gross edge must exceed 0.12% (double commission), which signals do not provide.

7. **1d signals now present.** Previously 0 (insufficient 1d indicators: 274 rows). After loading 2-year 1min history and aggregating to 1d: 213–215 signals per ticker. 1d timeframe can now be tested.

## 12. Conclusions & Next Steps

**Conclusion:** Rule-based strategies (patterns → signals → stop/take/holding) are NOT profitable after commission on MOEX top-3 over 2 years. The hypothesis "technical patterns generate tradeable edge" is rejected for this implementation, these tickers, and this timeframe.

**Next steps (options):**

- **A. Experiment without stops/takes:** Pure signal entry (ts≥3) + holding 24–48 bars, no fixed stop/take levels. VTBR buy&hold +0.17% suggests signals have directional edge that stops/takes destroy. If pure holding gives net > 0, the problem is exit rules, not signals. Quick experiment, one script.

- **B. ML (CatBoost/LightGBM):** Rebuild pipeline on labels (forward return over horizon), use indicators as features (not binary pattern flags). ML may find non-linear combinations that rule-based misses. Requires expanding to 30 tickers (~1500+ trades) to avoid overfitting. Large step, no guaranteed edge.

- **C. Expand to 30 tickers:** Load 1min candles for all 30 tickers (moex_1min_loader.py, ~5 hours), aggregate, recompute indicators/signals, rerun matrix on full universe. Confirms whether "rule-based is dead" holds on full sample, not just 3 tickers.

- **D. Accept result:** Document that rule-based is dead on MOEX top-3 over 2 years. Decide whether to pivot (different market, different frequency, fundamental approach) or pause the project.

**Recommended order:** C (expand to 30 tickers) → if confirmed dead → A (quick test without stops/takes) → if still negative → B (ML) or D (accept).
