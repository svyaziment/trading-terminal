# Правила тестирования стратегий

Правила и параметры тестирования стратегий в торговом терминале.

## 1. Паттерны (логика AND)

Стратегия строится из одного или нескольких паттернов. При выборе нескольких паттернов
сигнал срабатывает **только когда ВСЕ выбранные паттерны сработали на одном баре**
(логика AND). Один выбранный паттерн = бэктест только по этому паттерну.

| Паттерн | Условие (BUY) | Примечание |
|---|---|---|
| `levels_reversal` | цена в зоне поддержки 4h + подтверждение разворота на выбранных окнах | основной паттерн; задаёт стоп (поддержка) и тейк (сопротивление) |
| `rsi_oversold` | RSI-14 < 30 | индикаторный AND-фильтр |
| `macd_bullish` | гистограмма MACD > 0 | индикаторный AND-фильтр |
| `bb_lower` | close ниже нижней полосы Bollinger(20,2) | индикаторный AND-фильтр |

`levels_reversal` обязателен для сделки (задаёт стоп/тейк). Индикаторные паттерны
работают как дополнительные AND-фильтры поверх него.

## 2. Окна подтверждения (для `levels_reversal`)

Доступные значения (минуты): **1, 5, 10, 15, 20, 25, 30, 60, 90, 120**.

При выборе нескольких окон проверка осуществляется **последовательно для каждого
выбранного значения** и должна выполняться на **всех** (AND): последняя закрытая свеча
каждого выбранного таймфрейма должна закрыться выше зоны поддержки.

## 3. Комиссия (обязательно)

Одно значение round-trip, вводится вручную, например `0.06` (= 0.06% round trip,
0.03% на сторону). Применяется к каждой сделке (вход + выход).

## 4. Проскальзывание (обязательно)

Одно значение на сторону, вводится вручную, например `0.06` (= 0.06% на сторону).
Вход исполняется по `price * (1 + slip)`, выход по `price * (1 - slip)`.

## 5. Risk/Reward (опционально)

Два значения: `risk` (например 1.0) и `reward` (например 2.0). Вход только если
`reward / risk >= ratio` (например 2.0), т.е. `(take - entry) >= ratio * (entry - stop)`
плюс комиссия. Если не выбран — фильтр не применяется.

## 6. Глубина теста

| Глубина | История | Тикеры | Методы | Прогонов |
|---|---|---|---|---|
| **Экспресс** | 6 месяцев | 3 (SBER, LKOH, PIKK) | full-sample | ~10 |
| **Серьёзный** | 6 месяцев | 15 | full-sample + walk-forward | 40 |
| **Очень серьёзный** | 2 года (полная) | все (>250к минутных свечей) | full-sample + walk-forward | 100 |

## 7. Методы теста

- **Full-sample**: бэктест на всём выбранном периоде.
- **Walk-forward**: разбивка на полугодия (2024-H2, 2025-H1, 2025-H2, 2026-H1);
  PF по каждому окну, затем `PF>1` (сколько), `min PF`, `avg PF`.

Оба метода включены по умолчанию (чекбоксы); можно переключать независимо.

## 8. Количество прогонов

Bootstrap-итерации по списку сделок для оценки устойчивости (по умолчанию **40**,
одинаково для обоих методов, вводится вручную). `1` = детерминированный прогон.
В отчёте средний PF плюс `pf_min` / `pf_p25` для надёжности.

## 9. А/Б факторы

Каждая позиция помечается четырьмя независимыми факторами для сравнительного анализа:

| Фактор | Значения | Смысл |
|---|---|---|
| `signal_source` | `base` / `imbalance` | уровень+подтверждение vs +фильтр дисбаланса объёма |
| `window_mode` | `window` / `always` | окно входа 7-19 МСК vs 24/7 |
| `rr_mode` | `all` / `rr15` / `rr2` | без фильтра RR vs RR>=1.5 vs RR>=2.0 |
| `entry_mode` | `market` / `limit` | вход по best_ask vs лимитка по цене сигнала (TTL 20 мин) |

## 10. Метрики

| Метрика | Определение |
|---|---|
| `n` | количество сделок |
| `PF` | profit factor = валовая прибыль / валовый убыток |
| `Exp %` | матожидание = средняя чистая доходность на сделку |
| `WR` | win rate = % прибыльных сделок |
| `MaxDD %` | максимальная просадка от пика накопленной чистой доходности |

## 11. Хранение и переиспользование стратегий

После настройки стратегия именуется (английский, безопасные для БД символы) и
сохраняется в БД (имя + набор параметров). Сохранённую стратегию (единственный выбор
из списка БД) можно применить к любым тикерам из **вселенной ТОП-30 с >250к минутных
свечей** (множественный выбор чекбоксами).

## 12. Форматы отчётов

Бэктест:

| Тикер | n | PF | Exp % | WR | MaxDD % |
|---|---|---|---|---|---|

Walk-forward:

| Тикер | 2024-H2 | 2025-H1 | 2025-H2 | 2026-H1 | PF>1 | min PF | avg PF |
|---|---|---|---|---|---|---|---|
