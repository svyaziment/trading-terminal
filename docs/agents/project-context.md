## 15. Task Protocol

Development is task-based.

Each task should:
1. have a unique task ID;
2. be implemented as a bash script under scripts/;
3. produce artifacts under reports/<task_id>/;
4. produce report.json;
5. produce report.md;
6. produce log.txt.

Report statuses:
- success
- failed
- needs_human

Rules:
- do not edit code manually unless explicitly allowed;
- do not print secrets;
- do not run destructive commands;
- prefer idempotent operations;
- prefer small verifiable tasks;
- always check report.json before moving forward.
